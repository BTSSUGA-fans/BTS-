# BTS Fan Page Repository

BTS (Bangtan Sonyeondan), also known as the Bangtan Boys or Beyond the Scene, is a globally acclaimed seven-member South Korean boy band formed by Big Hit Entertainment in 2013. Consisting of Jin, Suga, J-Hope, RM, Jimin, V, and Jungkook, they are known for co-writing/producing their music, which covers topics like mental health, self-love, and social issues.

## 📋 Project Overview

This repository contains a fan-made BTS fan page website built with HTML, CSS, and JavaScript. The page celebrates BTS's music, members, and global impact.

## 🎯 Features

- **Responsive Design**: Works seamlessly on desktop, tablet, and mobile devices
- **Member Profiles**: Interactive cards showcasing all 7 BTS members
- **Music Integration**: Embedded Spotify player for exploring BTS discography
- **Photo Gallery**: Curated collection of BTS photos
- **Navigation**: Smooth scrolling navigation with sticky header
- **Modern Styling**: Purple color scheme with hover effects and animations

## 📁 File Structure

```
├── index.html          # Main fan page HTML file
├── README.md          # Project documentation
└── assets/            # (Future) Images and media files
```

## 🎨 Design Details

- **Color Scheme**: Purple (#8667c2) - representing BTS's brand
- **Typography**: 
  - Montserrat (headings)
  - Roboto (body text)
- **Responsive Breakpoints**: Optimized for devices 768px and below

## 🚀 How to Use

1. Open `index.html` in a web browser
2. Navigate using the menu links (About, Members, Music, Gallery, Contact)
3. Hover over member cards and gallery images for interactive effects
4. Click "Join the ARMY" button in the hero section
